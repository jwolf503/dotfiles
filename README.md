# My dotfiles

This directory contains the dot files for my systems

## Requirements

### Git

sudo pacman -S git

### Stow

sudo pacman -S stow

## Installation

First, clone repo into $HOME directory with git

$ git clone https://github.com/jwolf503/dotfiles.git
$ cd dotfiles

Then use GNU stow to create symlinks

$ stow .
